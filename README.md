# Taehoon Kim — Academic Website

Personal academic website for Taehoon Kim, Associate Research Fellow at the Korea Institute for Industrial Economics & Trade (KIET).

## Live site

[https://taehoonkim85.github.io](https://taehoonkim85.github.io)

## Structure

- `index.html` — homepage, research, education, and contact information
- `cv.html` — HTML curriculum vitae
- `styles.css` — responsive site styles

The site is a framework-free static website designed for GitHub Pages and published from the `main` branch.
